# Materials Research Workflows with AI Assistance

This repository demonstrates materials informatics (Pymatgen, ASE), quantitative electrochemical analysis (impedance.py), uncertainty-aware Bayesian experimental optimization (BayBE), and scientific LLM evaluation rubrics.

## Core Modules
1. Materials Informatics & Crystal Descriptor Extraction (Pymatgen, Matminer)
2. Quantitative Electrochemical Transport & Kinetics (EIS fitting, GITT apparent diffusivity, CV rate-dependence)
3. Constrained Bayesian Optimization & Gaussian Process Surrogates
4. Atomistic Simulation Workflows & CI-NEB Migration Barrier Calculations (ASE)
5. STEM Reasoning Evaluation Cases & Scientific Rubrics
